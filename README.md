# GameKill
一款高效的游戏屏蔽工具
## 安装
### 自动安装

> [!important]
> 请务必将文件夹放置在c盘根目录下，否则应用程序将完全失效

> [!WARNING]
> 若您之前已安装过此程序,请不要再次使用自动安装,否则极大概率会出现安装程序卡死问题,建议使用手动安装

首先,在发布页下载最新的"gamekill.7z"或"gamekill.zip"

然后,退出**所有杀毒软件**

第三步,将gamekill文件夹解压到C:\

完整的路径应该为这样`C:\gamekill\`

最后,运行 C:\gamekill\ 里面的"gamekill安装.exe",在弹出的窗口中点击下方最大的那个按钮即可开始安装,安装完成后电脑将会自动重启(其实那个窗口中只有一个按钮)

### 手动安装

> [!TIP]
> 若您的gamekill已安装过但出现问题,则可以在系统设置的应用列表中找到它并点击修复（如果有）

首先,在发布页下载最新的"gamekill.7z"或"gamekill.zip"

然后,退出**所有杀毒软件**

第三步,将gamekill文件夹解压到C:\

完整的路径应该为这样`C:\gamekill\`

最后,运行 C:\gamekill\ 里面的"AutoStart.exe",之后等待一分钟手动重启电脑即可完成安装
