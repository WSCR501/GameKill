# GameKill
一款高效的游戏屏蔽工具
## 安装
### 全新自动安装

在发布页下载最新的.exe文件

然后,退出**所有杀毒软件**

第三步,运行这个exe并按照指示操作

### 自动安装(0.4版本之前)

> [!important]
> 请务必将文件夹放置在c盘根目录下，否则应用程序将完全失效

> [!WARNING]
> 若您之前已安装过此程序,请不要再次使用自动安装,否则极大概率会出现安装程序卡死问题,建议使用手动安装(0.4版本之前)

首先,在发布页下载最新的"gamekill.7z"或"gamekill.zip"

然后,退出**所有杀毒软件**

第三步,将gamekill文件夹解压到C:\

完整的路径应该为这样`C:\gamekill\`

最后,运行 C:\gamekill\ 里面的"gamekill安装.exe",在弹出的窗口中点击下方最大的那个按钮即可开始安装,安装完成后电脑将会自动重启(其实那个窗口中只有一个按钮)

### 手动安装

> [!TIP]
> 若您的gamekill已安装过但出现问题,则可以在系统设置的应用列表中找到它并点击修复（如果有）

首先,在发布页下载最新的"gamekill.7z"或"gamekill.zip"

然后,退出**所有杀毒软件**

第三步,将gamekill文件夹解压到C:\

完整的路径应该为这样`C:\gamekill\`

最后,运行 C:\gamekill\ 里面的"AutoStart.exe",之后等待一分钟手动重启电脑即可完成安装

## Installation
### Brand New Automatic Installation

Download the latest .exe file from the release page

Then, exit **all antivirus software**

Step three, run this exe and follow the instructions

### Automatic Installation (Before Version 0.4)

> [!important]
> Make sure to place the folder in the root of the C drive, otherwise the application will not work at all

> [!WARNING]
> If you have installed this program before, do not use automatic installation again, as there is a high chance the installer will freeze. It is recommended to use manual installation (before version 0.4)

First, download the latest "gamekill.7z" or "gamekill.zip" from the release page

Then, exit **all antivirus software**

Step three, extract the gamekill folder to C:

The full path should look like this: `C:gamekill`

Finally, run "gamekill setup.exe" inside C:gamekill and click the largest button at the bottom of the pop-up window to start the installation. After installation, the computer will restart automatically (actually, that window only has one button)

### Manual Installation

> [!TIP]
> If your gamekill has been installed but is having issues, you can go to the app list in system settings and click Repair (if available)

First, download the latest "gamekill.7z" or "gamekill.zip" from the release page

Then, exit **all antivirus software**

Step three, extract the gamekill folder to C:

The full path should look like this: `C:gamekill`

Finally, run "AutoStart.exe" inside C:gamekill, then wait a minute and manually restart your computer to complete the installation
